# Support

## Where to ask

- **Documentation:** start with the repository `README.md` and `docs/`.
- **Usage questions:** open an issue with the `question` label. Use the feature or task
  form if the tracker requires it, and set the label.
- **Bug reports:** use the bug report form.
- **Security issues:** follow the [security policy](SECURITY.md). Never use a public
  issue.
- **Code of Conduct concerns:** follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## What to include

- Repository and version or commit.
- Operating system and architecture.
- The command or API request you ran.
- Expected and actual behavior.
- Relevant logs with tokens, credentials, and private paths redacted.
- Whether you can reproduce it from a clean checkout.

## What to expect

This is a volunteer, pre-alpha project. There is no guaranteed response time or support
contract. Maintainers may close questions that are answered by the documentation or that
do not include enough information to reproduce the problem.

## Before opening a question

1. Search existing issues.
2. Read the relevant documentation and examples.
3. Try the latest default branch if the issue might already be fixed.
4. Reduce the problem to the smallest reproducible case.

Do not paste secrets, personal data, or full production configuration.
